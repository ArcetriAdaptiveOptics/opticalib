Analyzer
========

.. automodule:: opticalib.analyzer
   :no-members:

Offline analysis of acquired data: single-frame reduction, cube-level
processing, spectral analysis and time-series diagnostics.  These are pure
functions -- they take arrays in and give arrays (or numbers) out, with no
device access and no persisted state.
